An entry for [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) on make.fun: the one-line resignation letter of a cron job that fired every minute for three years without a single thank-you, whose reward for perfect attendance was a "promotion" to firing every 30 seconds — twice the work, no raise. It is the flat, tired voice of a worker who has finally had enough, in a single line of 123 characters.

## Run it

```sh
python3 main.py
```

This writes the letter to `/output/entry.txt` (falling back to `./output/entry.txt` if `/output` is not writable) and prints the letter and its character count.
